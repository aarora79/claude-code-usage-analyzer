# Example Files

This directory contains sample output files that demonstrate the format and structure of the analyzer's reports.

## Important Note

The contents of this folder are for demonstration purposes only.

- The numbers and statistics shown here are fictional (generated from a fixed random seed) and do not represent real usage.
- These files exist to show the format of the JSON, Markdown, and Quarto reports.
- They do not convey actual usage data or real costs.

## Files

- `sample-analysis.json` - Example JSON output showing the complete analysis structure with all computed statistics, model combinations, and pricing information.
- `sample-report.md` - Example Markdown report showing the human-readable format.
- `sample-report.qmd` - Example Quarto document (render with `quarto render sample-report.qmd --to html`).

## Usage

Use these files to:

- Understand the output format before running the analyzer.
- See what metrics and statistics are included.
- Reference the structure for integration with other tools.

To generate your own real usage reports, run the analyzer against your actual Claude Code usage data.
