# Example Files

This directory contains sample output files to demonstrate the format and structure of the analyzer's reports.

## Important Note

⚠️ **The contents of this folder are for demonstration purposes only.**

- The numbers and statistics shown here are **fictional** and likely incorrect
- These files are meant to show the **format** of the JSON and Markdown reports
- They do **not** convey actual usage data or real costs

## Files

- **`sample-analysis.json`** - Example JSON output showing the complete analysis structure with all computed statistics, model combinations, and pricing information
- **`sample-report.md`** - Example Markdown report showing the human-readable format with executive summary, daily cost analysis, and model-specific insights

## Usage

Use these files to:
- Understand the output format before running the analyzer
- See what metrics and statistics are included
- Reference the structure for integration with other tools
- Preview the report layout

To generate your own real usage reports, run the analyzer with your actual Claude Code usage data.
